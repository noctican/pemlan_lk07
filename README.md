## Tujuan

Menerapkan pemahaman tentang Java GUI Programming untuk pemrosesan data di file. Data yang di olah adalah data siswa yang terdiri atas NIS, Nama Siswa dan Alamat. Adapun olah data tersebut adalah CREATE, READ, UPDATE dan DELETE (CRUD)


## Deskripsi Soal

Sebuah SMP mempunyai perpustakaan yag mempunyai catatan data siswa terdiri atas Nomor Induk Sekolah (NIS), Nama Siswa dan Alamat. Semua data tersebut bertipe string. Tugas Anda adalah membuat aplikasi JAVA GUI dimana:
1. Bagian Frame progran terdiri atas 4 bagian yaitu Judul Program, Bagian entri data, bagian tombol CRUD dan bagian Table.
2. Diawal program dijalankan maka semua data di tampilkan di tabel
3. Apabila terjadi penambahan data baru maka Data NIS tidak boleh sama. Jika sama maka ada exception handling
4. Data siswa disimpan di berkas siswa.csv, Harus ada penangan exception jika file tidak ada
5. Jika terjadi updating dan deleting data maka data di siswa.csv juga harus berubah
6. Yang dikumpulkan adalah kode program, screenshot output program untuk masing-masing CRUD. Berkas pengumpulan adalah file pdf.
7. Halaman depan laporan memuat Latihan Kerja ke ... , Judul LK, Anggota dan NIM serta Peran anggota, identifikasi prodi, departemen, fakultas, universitas dan tahun
